# Проект 1: Веб-приложение "Библиотека"

## Описание проекта
Данный проект представляет собой веб-приложение для автоматизации учета книг в местной библиотеке. Приложение позволяет регистрировать читателей, выдавать им книги и фиксировать возврат литературы.

## Используемые технологии
*   **Язык:** Java
*   **Фреймворк:** Spring Framework (с использованием `@Valid` и Spring Validator)
*   **База данных:** PostgreSQL (или любая другая SQL БД, поддерживающая команды `UPDATE`, `DELETE`, `JOIN`)
*   **Шаблонизатор:** Thymeleaf (используется `th:if`)
*   **Развертывание:** Предполагается локальное развертывание (пользователь может запустить проект локально для работы).

## Сущности базы данных
Проект использует две основные таблицы с отношением "Один ко Многим":

*   `Person`:
    *   `id` (автоматическая генерация)
    *   `fio` (ФИО, UNIQUE)
    *   `year_of_birth` (год рождения)
*   `Book`:
    *   `id` (автоматическая генерация)
    *   `title` (название)
    *   `author` (автор)
    *   `year` (год)
    *   `person_id` (FOREIGN KEY на таблицу `Person`)

## Необходимый функционал
Приложение реализует следующий набор функций, доступный через веб-интерфейс:

1.  **Управление людьми:** Страницы для добавления, изменения, удаления и просмотра списка всех читателей (`/people`).
2.  **Управление книгами:** Страницы для добавления, изменения, удаления и просмотра списка всех книг (`/books`).
3.  **Страница человека:** Просмотр данных читателя и списка взятых им книг. Если книг нет — отображается соответствующий текст.
4.  **Страница книги:** Просмотр данных книги и информации о том, кто ее взял. Если книга свободна, есть возможность назначить ее читателю через выпадающий список. Если книга занята, отображается кнопка "Освободить книгу".
5.  **Валидация:** Все поля ввода валидируются с помощью `@Valid`.
